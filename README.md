# DIAMONDX Baseball Store

Premium static baseball e-commerce storefront concept.

## Includes
- 42 catalog products
- 14 departments
- Search, filters and sorting
- Wishlist and cart with localStorage
- Quick view
- Position-focused collections
- Journal, FAQ and newsletter
- Dedicated support center
- Responsive design
- Local optimized image assets
- GitHub Pages friendly
